## The entry

One pickup line, 159 characters, spoken by a vending machine to a passing human:

> Hey, gorgeous — my coils have been turning all day just for you. Press B4 and I'll drop something sweet; exact change optional, but that smile? Non-refundable.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt` and prints it to stdout. It is fully deterministic — the same line on every run.

```sh
node main.ts
```
